# ShiftsLogger

This is a Shifts Logger where you can manage workers shifts.

## Features

* Viewing shifts
* Adding shifts
* Deleting shifts
* Updating shifts
* Calculating shift duration
* Validating shift data
* API connection using HTTP

## Built with

* C#
* .NET
* ASP.NET Core Web API
* Entity Framework Core
* SQL Server
* HttpClient
* Spectre.Console

## Project structure

* ShiftsLoggerApi — ASP.NET Core Web API responsible for database operations, validation and CRUD operations
* ShiftsLoggerApiClient — console application used to communicate with the API

## How to use

* Start `ShiftsLoggerApi`
* Start `ShiftsLoggerApiClient`
* Choose a menu option using ⬆️⬇️ and Enter
* Follow the instructions
* Done👍
